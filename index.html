      Set up the shared list

      One person does this once (about 3 minutes, free). Everything stored there is encrypted with the trip passcode.

      1. Open console.firebase.google.com and sign in with Google.
      2. Tap Create a project. Name it anything (e.g. chicago-trip). Turn off Google Analytics, then Create.
      3. In the left menu: Build → Realtime Database → Create Database. Pick United States, choose Start in test mode, then Enable.
      4. Copy the link at the top of the database page. It looks like https://chicago-trip-1234-default-rtdb.firebaseio.com/.
      5. Paste it below and tap Connect.
